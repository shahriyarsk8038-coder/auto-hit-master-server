Summary: "Indian Visa Auto Fill Master" is dedicated to protecting your privacy. This extension operates primarily on your local device. We do not sell, rent, trade, or transfer your personal data to third parties or advertising networks.

1. Introduction & Single Purpose

This Privacy Policy explains how Indian Visa Auto Fill Master ("we", "our", or "the Extension") collects, handles, stores, and protects user data. The single, exclusive purpose of this Extension is to assist users in autofilling and managing applicant information on the official Indian Visa Bangladesh online portal (https://indianvisa-bangladesh.nic.in/) efficiently and accurately.

2. Data Collection (What Data We Collect)

The Extension only handles data explicitly provided by the user for the purpose of completing visa forms:

  • Personal Identification Data: Applicant full name, date of birth, place of birth, nationality, gender, passport number, passport issue and expiry dates, citizenship/national ID number, and parent/spouse names as provided in visa applications.
  • Contact & Address Details: Present address, permanent address, phone number, and email address required for visa form fields.
  • Travel & Visa Details: Visa type, port of entry, expected travel dates, previous Indian visa numbers, and local hotel/reference contact details.
  • Uploaded Document Data: Passport image files or previous application PDF files uploaded directly by the user to extract applicant text via local and secure optical character recognition (OCR).
  • Account & License Information: User mobile number or license key used solely to authenticate extension access, credit balance, and subscription status.

3. Data Handling & Use (How We Use Your Data)

We use the collected information strictly for the following purposes:

  • Autofilling Visa Forms: Populating input fields on the official government visa application portal (https://indianvisa-bangladesh.nic.in/) based on user-supplied details.
  • Document OCR Parsing: Reading and parsing applicant data from passport scans and previous PDF applications selected by the user to save manual typing time.
  • License Verification: Checking license validity and account credit balance with our secure backend server (https://auto-fill-master-server.onrender.com/).

Prohibited Uses: We do NOT use personal data to display ads, profile users, perform credit assessments, or for any secondary purposes unrelated to visa application form-filling.

4. Data Storage & Security (Where and How Long Data is Kept)

  • Local Storage on Your Device: All applicant visa profile data, passport fields, and draft applications are stored locally in your browser using Chrome's secure chrome.storage.local API. This data stays on your computer.
  • Server-Side Data Minimization: Our backend server only records user license identifiers, phone numbers, and transaction reference numbers for billing and subscription management. Your personal passport form data is never permanently stored on our backend servers.
  • Security Measures: All network communication between the Extension and the backend or external OCR services takes place exclusively over encrypted HTTPS (TLS 1.3/1.2).
  • Data Deletion & Retention: You have full control over your data. You can delete or clear your stored applicant profiles at any time directly inside the Extension by clicking "Clear" or "Delete". Uninstalling the Extension instantly removes all locally stored data from your browser.

5. Data Sharing & Disclosure (Who We Share Data With)

Zero Data Selling: We do NOT sell, rent, monetize, or trade your personal or sensitive data to third parties, data brokers, or advertising networks under any circumstances.

Data is shared solely in the following limited, operational contexts:

  • Official Destination Portal: Data is entered into the official government website chosen by the user (https://indianvisa-bangladesh.nic.in/) when the user initiates autofill.
  • Ephemeral OCR Processing: When the user chooses to extract text from a passport image using AI/OCR models (Google Gemini API / CapMonster), the image is sent via encrypted HTTPS strictly for real-time text extraction and is not stored or used for model training.
  • Legal Compliance: We will only disclose information if required by law or a valid government subpoena.

6. Chrome Web Store Policy Compliance

In full compliance with the Google Chrome Web Store Developer Program Policies:

  • The Extension requests only permissions strictly necessary for its functionality (e.g. storage for local saving, activeTab and host permissions for the visa portal).
  • The Extension does not contain remotely hosted executable code.
  • The Extension does not collect personal information without user knowledge or action.
